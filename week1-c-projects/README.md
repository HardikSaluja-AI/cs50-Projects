# CS50 Week 1 - C Projects

This folder contains my Week 1 programming assignments from the CS50 course, written in the C language. The focus this week was on understanding syntax, loops, functions, and greedy algorithms.

---

## ✅ hello.c
A simple program to print “hello, world” using C and get familiar with compilation and syntax.

**Key Concepts**:
- Printing text
- Using `printf()`
- Basic C structure

---

## ✅ mario.c
Prints a pyramid of `#` characters based on user input (the "less comfortable" version).

**Key Concepts**:
- Loops (`for`)
- Nested loops
- Input validation with `get_int()`

---

## ✅ cash.c
Calculates the minimum number of coins (quarters, dimes, nickels, pennies) for a given amount of change.

**Key Concepts**:
- Greedy algorithms
- Functions
- Conditionals & loops

---

## 📚 Skills Learned:
- Writing and compiling C programs
- Breaking problems into subproblems (functions)
- Using CS50 library functions like `get_int`
